# Val quirúrgico

Tracker de hábitos y rachas — ciclo de 90 días (21/09/2026 → 19/12/2026).

App web instalable (PWA): funciona sin internet y los datos quedan en el celular.

**Abrir:** https://jcoronadoccorimanya08-jpg.github.io/val-quirurgico/

## Instalar en el celular
- **Android (Chrome):** menú ⋮ → "Instalar aplicación"
- **iPhone (Safari):** Compartir → "Añadir a pantalla de inicio"

Ver `LEEME.md` para el detalle.
